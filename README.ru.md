# Moumusic

[简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português](README.pt.md)

Moumusic — лёгкий музыкальный проигрыватель от moumou для браузера и iOS. Он поддерживает поиск, воспроизведение, избранное, тексты песен, плейлисты и загрузку без регистрации.

## Возможности

- Переключение между установленными источниками: NetEase Cloud Music, QQ Music, Kuwo, Luoxue и другими.
- Импорт источников, совместимых с LX Music / MusicFree, через раздел «Настройки». Источники сторонних разработчиков не входят в приложение.
- Выбор качества 128, 192, 320, 740 и 999 кбит/с в зависимости от возможностей источника.
- Тексты песен, полноэкранный режим текста, избранное, импорт и экспорт плейлистов, загрузка и синхронизация источников между устройствами.
- Официальные чарты, например горячие песни NetEase Cloud Music, если их предоставляет установленный источник.

## Воспроизведение на iOS

Нативное приложение iOS поддерживает фоновое воспроизведение и передаёт обложку, название, исполнителя, альбом, прогресс и управление на экран блокировки и в Пункт управления. Полноэкранный текст и Live Activity / Dynamic Island показывают текущую строку песни. iOS не предоставляет сторонним приложениям отдельное поле текста в медиакарточке Пункта управления.

## Источники

Проект отделён от музыкальных источников: файлы источников не входят в репозиторий или IPA. Откройте «Настройки» и вставьте URL источника для установки. Поддерживаются распространённые методы и поля LX Music / MusicFree: `search`, `getMediaSource`, `getLyric`, `name`, `singer`, `pic`, `interval`.

## Локальная разработка

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm test
pnpm build
```

## IPA без подписи

Для сборки iOS нужны macOS 26 и Xcode 26:

```bash
pnpm build:ipa
# → ios/build/unsigned/Moumusic-unsigned.ipa
```

IPA без подписи нельзя установить на iPhone напрямую. Сначала подпишите его сертификатом разработчика Apple и provisioning profile.
